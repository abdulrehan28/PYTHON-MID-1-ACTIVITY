PYTHON ACTIVITY-BASED LEARNING
Combined solutions for case studies 23, 28, 30, 38, 66, 72, 76, 77, 81 and 94

FILES
1. combined_10_python_programs.py
   Complete Python source code for all ten case studies. Run it with Python 3.
2. combined_10_output.txt
   Text output captured from the combined program.
3. combined_10_output_screenshots.pdf
   Terminal-style output pages for all ten case studies.
4. combined_10_problem_algorithm_flowchart_output.pdf
   Problem statements, objectives, assumptions, algorithms, pseudocode,
   flowcharts, and sample output for each case study.

HOW TO RUN
- Install Python 3 if it is not already installed.
- Keep combined_10_python_programs.py in a folder.
- Open Command Prompt/Terminal in that folder.
- Run: python combined_10_python_programs.py
  (On some systems, use: python3 combined_10_python_programs.py)

NOTES
- The program uses basic Python concepts: variables, conditions, loops,
  strings, lists, nested lists, tuples, and functions.
- Sample data and policy thresholds are explicitly included in the code
  because the assignment sheet does not supply real datasets or detailed
  numerical policies for every case study. Change them as required by
  your faculty.
- Case 30 uses the sample registration format: 3 uppercase letters plus
  7 digits. Email checks are basic format checks, not full email verification.
- Case 38 simulates a sequence of ATM operations instead of taking live input.
- Case 66 risk rules: average marks below 40, attendance below 75%, or lab
  score below 50%; 2 or more risk factors = HIGH, 1 = MEDIUM, 0 = LOW.
- Case 72 example rates: Rs. 8 per kWh and Rs. 20 per 1,000 litres.
- Case 76 adds up to 3 grace marks to a subject below 40, without exceeding 100.
- Case 77 tariff: first 100 units at Rs. 3/unit, next 100 at Rs. 5/unit,
  above 200 at Rs. 7/unit; fixed charge Rs. 50 and Rs. 20 rebate below 60 units.
- Case 81 uses a sample seating matrix and ticket list.
- Case 94 allocates available supplies in priority order (1 is most urgent).

The solutions are educational examples and should be adjusted if your
instructor provides different rules, data, or output requirements.
